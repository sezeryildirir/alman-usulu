# 🇩🇪 Alman Usulü - Grup Gider Paylaştırıcı

Arkadaşlarınızla etkinlik yaptığınızda grup giderlerini eşit şekilde paylaştırmak için basit ve kullanışlı bir web uygulaması.

## 🎯 Özellikler

✅ **Etkinlik Yönetimi** - Her etkinliği ayrı isimle oluştur  
✅ **Katılımcı Ekleme** - Arkadaşlarını etkinliğe ekle  
✅ **Gider Girişi** - Herkes kendi harcamalarını ekleyebilir  
✅ **Otomatik Hesaplama** - Kim kime ne kadar vereceğini göster  
✅ **Arşivleme** - Etkinlik bitince arşivle  
✅ **Kalıcı Saklama** - Veriler tarayıcıda kaydedilir  

## 🚀 Canlı Demo

👉 [Alman Usulü - Live Demo](https://alman-usulu.vercel.app)

## 💻 Lokal Çalıştırma

Dosyayı doğrudan tarayıcıda aç:
```bash
# Tarayıcıda aç
open index.html
```

Veya local server ile (localStorage desteği için):
```bash
# Python 3
python -m http.server 8000

# Veya Node.js
npx http-server
```

Ardından tarayıcıda `http://localhost:8000` aç.

## 📝 Nasıl Kullanılır?

1. **Yeni Etkinlik Oluştur** - Etkinlik adı gir ve "Etkinlik Oluştur"a tıkla
2. **Katılımcıları Ekle** - Arkadaşlarının isimlerini gir
3. **Harcamaları Kaydet** - Kim ne için kaç lira harcadıysa gir
4. **Ödeme Planını Gör** - "A kişi B kişiye X lira vericek" şeklinde gösterilir
5. **Etkinliği Arşivle** - Bitince arşivle (veriler silinmez)

## 🛠️ Teknoloji

- **Frontend**: Pure HTML, CSS, JavaScript
- **Storage**: Browser LocalStorage
- **Responsive**: Mobil ve desktop uyumlu
